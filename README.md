# 🎮 JJS Script

Скрипт для игры **Jujutsu Shenanigans** (Delta Executor).

## ✨ Функции
- 🎨 Плавная анимация запуска
- 👤 Hello, [юзернейм]
- 🔍 Scanning Players X/Y
- 🌾 AutoFarm (стоит сзади цели)
- ⚔️ AutoAttack (M1 + Tool Activate)
- 🎯 Target HUD сверху экрана (ник, аватар, HP)
- 🔽 Target Selector (выбор игрока)
